Use this once, on a new empty database (for example after moving to Neon), to bring back everything from a backup file: students, accounts, subjects, timetable and attendance.

  • The backup must be the .zip that contains attendance_backup.json.
  • Restore is blocked when students, subjects or attendance already exist, so live data can never be erased.
  • After restoring you are logged out. Log in with the admin username and password from the backup, not the one you used to open this page.
